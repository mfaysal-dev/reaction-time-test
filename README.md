# Reaction Time Test

Test your reaction time in milliseconds. Wait for green, then tap as fast as you can. Get your average over 5 tries, a rank from 'Sloth' to 'F1 driver', and a shareable score card.

Live: https://mfaysal.com/free-tools/reaction-time-test/

- 100% client-side HTML/CSS/JS, no API keys, no tracking
- Shareable PNG result card (Web Share API / download)

Run locally: open `public/index.html`.
